# Download and open exercises

Each course has its own page and its own workspace, a VS Code window that holds its downloaded exercises.

- **Show Course Details** opens the course's page. The course's menu in the **Courses** view of the TestMyCode sidebar has it too.
- On the course's page, **Download** gets the exercises and **Open Course Workspace** opens the course's window. Its exercises are folders in the Explorer.
- **Continue** on the course's page, or **Next** in a passing result, opens the next exercise to do.

The first time you open a course workspace, TestMyCode asks you to trust it, and VS Code asks whether you trust the authors of its files. Choose **Trust Workspace & Continue** (**Yes, I trust the authors** in older VS Code versions): TestMyCode needs a trusted workspace to run tests and submit. Each exercise you download while the course workspace is open asks again; answer **Yes**. If you said no, **Trust Course Workspace** in the Courses view asks again.

When the course publishes new or updated exercises, the course's page says so and offers to download them.
