# Pre-release versions

TestMyCode publishes pre-release versions with changes that are not in the stable release yet, for course staff and anyone who wants to try them early. **Thank you to everyone who uses them and [reports the issues](https://github.com/rage/tmc-vscode/issues/new/choose) they run into.**

Pre-release versions replace the Insider version and its `testMyCode.insiderVersion` setting, which was removed in 4.0.0.

## Switching to a pre-release

1. Open the Extensions view in VS Code and select **TestMyCode**.
2. Select **Switch to Pre-Release Version**, then restart the extensions when VS Code asks.

VS Code keeps you on pre-release versions and updates you to newer ones, and to a stable release when it is the newer version. The [changelog](https://github.com/rage/tmc-vscode/blob/master/CHANGELOG.md) lists what each version changes.

## Switching back

On the same page, select **Switch to Release Version**. VS Code installs the latest stable release.

## Reporting an issue

- Check whether the problem also happens with the stable release.
- Open a [bug report](https://github.com/rage/tmc-vscode/issues/new/choose), answer its questions, and say which pre-release version you use. "TestMyCode: Show Logs" opens the log, which helps us find the cause.
