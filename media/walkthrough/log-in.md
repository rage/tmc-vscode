# Log in with courses.mooc.fi

One courses.mooc.fi account works for every TestMyCode course, on courses.mooc.fi and on tmc.mooc.fi.

1. Select **Log In**. TestMyCode shows a login code.
2. Select **Open courses.mooc.fi**. The site opens in your browser, where you log in if you are not already. VS Code may first ask whether to open the site: choose **Configure Trusted Domains** and trust courses.mooc.fi, and it stops asking for this and every later link to the site.
3. Check that the page shows the same code, then approve the login. TestMyCode waits until you do, then lists your courses to add.

VS Code never sees your password. To log out, select the account item in the status bar, or run **TestMyCode: Log Out**.
