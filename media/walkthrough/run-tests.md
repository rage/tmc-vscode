# Run Tests

**Continue with an Exercise** opens the next exercise to do. With a file of an exercise open, the editor's title bar shows **Run Tests** (the beaker) and **Submit** (the cloud), and the status bar names the exercise and its points.

Run Tests runs the exercise's tests on your computer and shows which pass in the **Test Results** view. Nothing is sent anywhere.

The status bar item shows a spinner while the tests run. Select it for the other exercise actions: Get Help, Reset Exercise, History, or Show in Courses View.
